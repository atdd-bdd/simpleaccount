# archive

Finished work, kept because the reasoning in it is still worth reading.

- `completed-tasks.md` — the twenty-two items of `tasks.md` that are done,
  verbatim, under the headings they were written under. `tasks.md` holds what
  is owed.
- `completed-todo.txt` — the items of `TODO.md` and `more to do.txt` that are
  done, verbatim, each with a line saying what closed it and which task number
  it became. `more to do.txt` is gone from the root: every item on it turned
  out to be finished, the last of them -- the standard chart for a new book --
  found to be built while the user's guide was being written.

Nothing here is a live list. If an item needs reopening, move it back rather
than editing it in place, so that the record of what was decided stays whole.

`categories-for-review.txt` is deliberately **not** here. It is a report of
431 category rows with their all-dates totals and the year each was last
used — an input to a decision the author has not made yet, not finished work.
It stays in the root for that reason.
