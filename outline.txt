Downloads 
	Downloads in QFX or CSV.  When a download is imported, the bank and account id will be read from the QFX file or from the name of the CSV file.  This information will be display in a dialog box and potentially edited before the download begins.  
	A progress dialog should show up while the download is being imported.  
	Downloads may contain new or duplicated transactions.   
	A duplicate is an entry that 
		a. matches the QFX id of an existing entry 
			(if the amounts don't match, a dialog should come up) 
		b. matches the payee, amount, and date of an existing entry 
		More detailed rules have been provided . 
	Once the import is compete, the user has the opportunity to review it, before accepting it.  Duplicates should be marked in the list.  The user can ask that they be hiden.  If there are payee matches, the categories will be assigned to those transactions automatically.
